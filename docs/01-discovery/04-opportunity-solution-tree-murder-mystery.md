## Opportunity Map

세 Opportunity를 식별하고, 그중 하나를 1차 POC로 선택한다.

### Opportunity 1: 역할 몰입 자유도 (전원 플레이어화)

**문제:** 진행자 1인이 카드·힌트·규칙을 운영하느라 자기 캐릭터에 몰입하지 못하고, 나머지 플레이어는 다음 단계가 언제 오는지 눈치만 본다. "전원이 진행자에 묶이지 않은 채 캐릭터에 몰입한다"는 수요가 업계 어느 플레이어에게도 1차 타깃이 아님.

**근거 (캔버스):** Phase 3 "GM 모델은 해결책이 아니라 메타 부담을 한 사람에게 집중시키는 절충안" — GM은 역할 몰입을 즐길 수 없는 사람 역할을 떠맡음.

**MVP 접근:** Opp 1은 별도 Solution을 선택하지 않고, **Opp 3의 1차 POC가 떠받치는 위에 시나리오 저자가 밀담·아이템·장소·말투 가이드 같은 모듈로 채워 넣을 그릇(2차 가치)** 으로 둔다 (PRD §4.3 핵심 가치 우선순위 참조).

### Opportunity 2: 메타 부담 주의력 분산

**문제:** 규칙·카드·힌트·진행 순서가 순차 수동 공유라 흐름이 끊김. "룰이 뭐였지?" 발화로 몰입이 깨짐.

**근거 (캔버스):** Phase 1 증상 — 규칙 장벽, 대기 비용, 중간 혼선.

**MVP 접근:** Opp 2는 별도 Solution을 선택하지 않고, **Opp 3의 MVP 산출물(엔진·진행 자동화·초대 번호 합류)이 자연히 해소하는 파생 효과로** 본다.

### Opportunity 3: 즉시성·접근성 장벽

**문제:** 친구 3-6명이 이미 모였고 시간도 있는데, 물리 게임팩 없음 / 보드게임장 예약 실패 / 당일 결심 불가로 지금 시작할 수가 없음. 포기 또는 게임장 이동.

**근거 (캔버스):** Phase 2 결과 "포기 또는 보드게임장 이동"; 현상 유지 수혜자가 공간+진행+IP 번들 독점.

**Selected Solution:** Solution 3A — 초대 번호 시작 + 게스트 합류 (본 문서 [Selected POC](#selected-poc) 참조)

## Selected POC

MVP는 **Opportunity 3 단일 POC**에 자원을 집중한다. Opp 1(역할 몰입 자유도)은 시나리오 저자가 모듈로 채워 넣을 2차 가치 그릇이며, Opp 2(메타 부담)는 Opp 3 산출물의 파생 효과로 해소된다.

### 1차 POC — Opportunity 3 × Solution 3A (초대 번호 시작 + 게스트 합류)

**무엇:** 호스트 1명이 시나리오 선택 → 6자리 초대 번호 생성 → 다른 플레이어가 번호 입력으로 합류 (회원가입 없이 게스트 모드, 닉네임만).

**왜 이 POC인가:**

- 보드게임장·퍼블리셔의 "공간+진행+IP 번들" 독점 구조 밖의 공백 포지션을 직접 점유
- 구현 공수 대비 임팩트 큼 — UI·세션 합류 플로우에 집중된 작업

### MVP 콘텐츠 — 자체 제작 오리지널 시나리오 1편

캐릭터 수·복잡도·동기 구조·말투 가이드 포함 여부 등 **시나리오 사양은 시나리오 저자 재량.** 플랫폼은 그릇만 제공하며 권장값을 강제하지 않는다 (PRD §5.1).
