## Desired Outcome

**Primary:** 세션 내 역할 몰입 극대화 + 플랫폼 반복 사용

| 지표 | 측정 방식 | 판정 가설 |
| --- | --- | --- |
| **첫 세션 도달률** (모인 시점 → 단계 1 도입 진입까지 중앙값) | 호스트 시나리오 선택 시각 → 단계 1 진입 이벤트 | 즉시성 — "이미 모인 그룹이 지금 시작한다" |
| **세션 완주율** (입문자 포함 그룹 별도 집계) | 단계 9-A(범인 공개) 도달 여부 | 입문자 장벽(규칙/연기) |
| **룰·도움말 조회 이벤트 횟수** | 인앱 탭 이벤트 카운트(라운드 번호별 집계) | 메타 부담 자동화 효과 |
| **세션 종료 디브리프** (몰입 1–5 + 원인 귀속 5지선다) | 인앱 설문 | 몰입 주관 평가 + 콘텐츠/플랫폼 효과 분리 |
| **플랫폼 재플레이율** (4주 내 **다른 시나리오** 플레이) | 사용자×시나리오 매트릭스 | 콘텐츠 전략(자체 제작 + UGC) 유효성 |

**지표 설계 원칙:**

- 머더 미스터리는 범인 공개 후 동일 시나리오 재플레이 불가 → 재플레이율은 **다른 시나리오로의 이동** 기준
- 눈맞춤·연기 톤 같은 카메라 의존 지표는 프라이버시·UX 부담으로 제외
- 스마트폰 활성 시간은 BYOD 구조상 항상 ~100% 근처 → 신호 아님, 제외
- 캐릭터 발화 vs 메타 발화 비율은 음성 인식 + 발화 분류 ML 필요 → MVP 범위 밖, 제외
- 3초 몰입 펄스 탭은 "측정 행위가 몰입을 깬다"는 역설로 제외

## Opportunity Map

세 Opportunity를 식별하고, 이 중 두 개를 번들 POC로 선택한다.

### Opportunity 1: 입문자 역할 몰입 미경험

**문제:** 머더 미스터리 완전 입문자는 "역할 몰입이라는 재미" 자체를 경험해본 적 없음. 규칙과 씨름하다 게임이 끝남.

**근거 (캔버스):** Phase 2 "소외된 목소리" — 업계 어느 누구도 이들을 타깃으로 설계하지 않음.

**움직일 지표:** 입문자 포함 그룹 완주율, 디브리프 몰입 점수

**Selected Solution:** Solution 3 — 입문자 전용 "첫 사건" 시나리오 (본 문서 [Selected POC 2차](#selected-poc) 참조)

### Opportunity 2: 메타 부담 주의력 분산

**문제:** 규칙·카드·힌트·진행 순서가 순차 수동 공유라 흐름이 끊김. "룰이 뭐였지?" 발화로 몰입이 깨짐.

**근거 (캔버스):** Phase 1 증상 — 규칙 장벽, 대기 비용, 중간 혼선.

**움직일 지표:** 룰·도움말 조회 횟수(라운드 번호별), 완주율

**MVP 접근:** Opp 2는 별도 Solution을 선택하지 않고, **Opp 1·Opp 3의 MVP 산출물(엔진 · 진행 자동화 · QR 합류)이 자연히 해소하는 파생 효과로** 본다. 전용 Solution(자동 스크립트 엔진·JIT 규칙 공개·힌트 자동 드립)은 본 MVP 이후로 이연.

### Opportunity 3: 즉시성·접근성 장벽

**문제:** 친구 3-6명이 이미 모였고 시간도 있는데, 물리 게임팩 없음 / 보드게임장 예약 실패 / 당일 결심 불가로 지금 시작할 수가 없음. 포기 또는 게임장 이동.

**근거 (캔버스):** Phase 2 결과 "포기 또는 보드게임장 이동"; 현상 유지 수혜자가 공간+진행+IP 번들 독점.

**움직일 지표:** 첫 세션 도달률, 재플레이율

**Selected Solution:** Solution 3A — QR 원터치 시작 + 게스트 합류 (본 문서 [Selected POC 1차](#selected-poc) 참조)

## Selected POC

MVP는 **두 Opportunity를 번들로 담는다**.

### 1차 POC — Opportunity 3 × Solution 3A (QR 원터치 시작 + 게스트 합류)

**무엇:** 호스트 1명이 시나리오 선택 → QR 코드 생성 → 다른 플레이어 스캔으로 자동 합류 (회원가입 없이 게스트 모드, 닉네임만). 모인 순간부터 단계 1(도입) 진입까지 **목표 중앙값 ≤ 5분**.

**Hypothesis:**

> "모였다 → 게임 시작" 사이의 마찰(계정 생성·친구 추가·링크 전달·게임팩 구매·보드게임장 예약)이 큰 포기 원인. 마찰을 제거하면 첫 세션 도달률이 급상승하고, "당일 결심" 플레이가 반복 가능한 행동 패턴으로 자리 잡는다.

**왜 이 POC인가:**

- 보드게임장·퍼블리셔의 "공간+진행+IP 번들" 독점 구조 밖의 공백 포지션을 직접 점유
- 첫 세션 도달률이라는 단일 지표가 가치 전달 여부를 직접 판정
- 구현 공수 대비 임팩트 큼 — UI·세션 합류 플로우에 집중된 작업

### 2차 POC — Opportunity 1 × Solution 3 (입문자 전용 "첫 사건" 시나리오)

**무엇:** 자체 제작 시나리오 중 1편을 **입문자 친화 설계**로 제작

- 캐릭터 3–4명 (많지 않음)
- 단순한 동기 구조
- 캐릭터 카드에 **말투·자세 가이드 2–3줄 포함** (예: "허세 많고 말이 빠름. 위기엔 농담으로 회피")
- 복잡한 트릭 대신 감정 드라마 중심

**Hypothesis:**

> 입문자의 장벽은 "규칙"이 아니라 **"내 캐릭터를 어떻게 연기해야 할지 모름"**이다. 캐릭터 수가 적고 말투 가이드가 담긴 카드로 설계된 시나리오라면, 입문자 포함 그룹의 완주율이 경험자 그룹 완주율의 80% 이상에 도달하고, 디브리프 몰입 점수가 3.5/5 이상을 기록한다.

**왜 이 POC인가:**

- 콘텐츠 전략("자체 제작 시나리오로 품질 기준 확보")과 일관
- 1차 POC로 유입된 그룹이 "첫 세션에서 재미를 못 보고" 이탈하지 않도록 보장
- 입문자 완주율이 가정(입문자 장벽 = 연기 가이드 부재)을 직접 판정

### 번들 측정 설계

MVP 출시 시 두 POC를 동시에 활성화하고, 지표를 **병렬 측정**한다 — 첫 세션 도달률(1차)과 입문자 완주율·몰입·재플레이(2차).

## Experiment Plan

### 소프트 런칭 (MVP 출시 후 30일)

- **기간:** 4–8주
- **방식:** 입문자 전용 시나리오 1편 풀 제작 + QR 원터치 시작·게스트 합류 플로우 구현 → 플랫폼 출시
- **참가자:** 입문자 포함 그룹 30–50팀
- **측정 지표:**
  - 첫 세션 도달률 (모인 시점 → 단계 1 진입 중앙값)
  - 완주율 (입문자 포함 그룹 vs 경험자 그룹, 같은 시나리오 내 비교)
  - 룰·도움말 조회 이벤트 횟수 (라운드 번호별)
  - 디브리프 몰입 점수 + 원인 귀속 질문
  - 4주 내 재플레이율 (다른 시나리오로 이동)
- **성공 기준:**
  - 첫 세션 도달률 중앙값 ≤ 5분, 90 퍼센타일 ≤ 10분
  - 입문자 포함 그룹 완주율 ≥ 경험자 그룹의 80%
  - 디브리프 몰입 점수 평균 ≥ 3.5/5
  - 4주 내 재플레이율 ≥ 30%
- **초기 5–10팀은 연구자 배석 관찰** (텔레메트리 해석 기준 보정 + pre-session 0-A~0-E 구간 이탈 원인 관찰)

## 실험 설계 주의점

**교란 변수 — 콘텐츠 품질 vs 플랫폼 자동화:**
입문자 전용 시나리오 1편만 내면 "스토리가 좋아서 완주했나, 플랫폼이 메타 부담을 풀어줘서 몰입했나"를 분리할 수 없음.

**대응 — 디브리프 원인 귀속 질문 (복수 선택):**

> 이 세션을 완주하고 재밌었던 이유는? (해당되는 것 모두 선택)
>
> 1. 스토리가 재밌어서
> 2. 진행이 자동이라 룰에 덜 신경써도 돼서
> 3. 내 캐릭터를 연기할 만했어서
> 4. 친구들과의 분위기가 좋아서
> 5. 기타 (자유 기술)

응답 분포로 "콘텐츠 효과"와 "플랫폼 효과"를 정성 분리.
